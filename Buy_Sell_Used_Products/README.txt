ReUseHub — Buy & Sell Used Products
===================================

PROJECT CONTENTS
----------------
Buy_Sell_Used_Products/
  index.html   Main website structure
  style.css    Responsive layout and styling
  script.js    Sample listings and interactive functionality
  README.txt   This guide

HOW TO RUN IN GOOGLE CHROME
---------------------------
1. Download Buy_Sell_Used_Products.zip.
2. Extract / unzip the ZIP file to a folder on your computer.
3. Open the extracted Buy_Sell_Used_Products folder.
4. Double-click index.html.
5. If prompted, choose Google Chrome. You can also right-click index.html
   and choose Open with > Google Chrome.

No installation, server, backend, database, API, or build step is required.
The project runs locally from index.html. An internet connection may be
needed only for the optional Google Fonts import; system fonts are used as
fallbacks if it is unavailable.

FEATURES
--------
- Responsive marketplace with eight sample products.
- Product search across name, category, description, location and condition.
- Working category filters and live product count.
- View Details modal with product information.
- Buy Now demonstration modal with required name and phone validation.
- Confirmation screen that clearly explains no real transaction takes place.
- Sell form with validation that adds new products to the listing.
- Favourites button feedback, empty search state, close button, outside-click
  modal closing, and Escape-key modal closing.
- Sample product visuals use emoji and CSS; external product images are not
  required.

IMPORTANT DEMONSTRATION NOTE
----------------------------
This is a front-end college project. Product listings are stored in browser
memory while the page is open. Refreshing the page resets new listings to the
eight sample products. Purchases are simulations only: no payment is taken,
no order is sent, and form data is not submitted to a server.

SCREENSHOT SUGGESTIONS
----------------------
1. Open index.html in Chrome and maximize the browser window.
2. Capture the home page with the ReUseHub header and hero section.
3. Scroll to “Buy & Sell Used Products” to capture all eight product cards.
4. Click “View Details” on a product to capture the details modal.
5. Click “Buy Now” and fill the demo form to capture the purchase flow.
6. Scroll to “Have something to sell?” to capture the listing form.
7. Resize Chrome to a narrow window to inspect the responsive mobile layout.

TECHNOLOGIES
